# DNA是什么？管件行业的DN数字命名体系详解

在管件和管道行业中，**DN**是最基本也最重要的规格标识。DN是**Diamètre Nominal**（法语，意为"公称直径"）的缩写，也常被误读为"DNA"。DN是国际通用的管道和管件**规格编号系统**，用于标识管道、阀门、管件的名义尺寸。理解DN的含义及其与实际尺寸的关系，是管件行业从业人员的基本功。

## 什么是DN？

**DN（公称直径）**是国际标准化组织（ISO）规定的管道规格标识方法，用于统一标识管道和管件的**名义尺寸**。DN后面的数字代表管道的**公称口径**，单位为毫米。

**重要概念**：DN值**既不是管道的内径，也不是管道的外径**，而是一个用于标准化的**参考数值**。

### DN的编号系列

DN采用标准化的数字系列：

DN15、DN20、DN25、DN32、DN40、DN50、DN65、DN80、DN100、DN125、DN150、DN200、DN250、DN300、DN350、DN400...

注意DN编号并不是连续的整数，某些数值被跳过（如DN55、DN75不存在），这是为了与历史上的英制尺寸系统对应。

## DN与英制尺寸的对应关系

DN编号体系与英制管径系统有对应关系：

| DN | 英制尺寸 | 近似参考 |
|----|---------|---------|
| DN15 | 1/2" | 半寸管 |
| DN20 | 3/4" | 三寸管 |
| DN25 | 1" | 一寸管 |
| DN32 | 1-1/4" | 一寸二管 |
| DN40 | 1-1/2" | 一寸半管 |
| DN50 | 2" | 两寸管 |
| DN65 | 2-1/2" | 两寸半管 |
| DN80 | 3" | 三寸管 |
| DN100 | 4" | 四寸管 |
| DN125 | 5" | 五寸管 |
| DN150 | 6" | 六寸管 |

## DN与实际尺寸的关系

DN值与管道的实际内径和外径**不直接相等**，但存在一定的对应关系。不同材质和标准的管道，同一DN值对应的实际尺寸不同。

| DN25 | 28.0 | 0.8-1.0 | 26.0-26.4 |
| DN32 | 35.0 | 1.0-1.2 | 32.6-33.0 |
| DN40 | 42.0 | 1.0-1.2 | 39.6-40.0 |
| DN50 | 54.0 | 1.0-1.2 | 51.6-52.0 |
| DN65 | 76.1 | 1.0-1.5 | 73.1-74.1 |
| DN80 | 88.9 | 1.0-1.5 | 85.9-86.9 |
| DN100 | 108.0 | 1.0-2.0 | 104.0-106.0 |

### PPR塑料管

| DN | 外径(mm) | S2.5壁厚(mm) | S3.2壁厚(mm) |
|----|---------|-------------|-------------|
| DN20 | 25.0 | 5.1 | 4.1 |

**注意**：PPR管的DN值更接近管道的**内径**，与不锈钢管的情况不同。

## 为什么DN不等于实际直径？

DN之所以不等于管道的实际直径，是因为历史原因：

1. **早期钢管标准**：最初钢管的规格按内径定义，但随着材料壁厚的变化，同一"公称直径"的内径和外径都在变化
2. **壁厚差异**：不同壁厚系列（SCH10、SCH40、SCH80等）的管道，外径相同但内径不同
3. **统一命名**：为简化规格标识，国际标准采用DN作为统一的参考数值

## DN在不同管件类型中的应用

| 管件类型 | DN标识位置 | 重要性 |
|---------|-----------|--------|
| 卡压管件 | 管件本体标注 | 核心——标识管件口径 |
| 螺纹管件 | 螺纹规格标识 | 核心——螺纹与DN对应 |
| 法兰管件 | 法兰标准标注 | 核心——法兰密封面按DN |
| 阀门 | 阀体铸字标识 | 核心——阀门通径按DN |
| PPR管件 | 管件外包装标注 | 核心——标识管件适配口径 |

## 相关的规格标识

除了DN，管件行业还有其他常见的规格标识：

| 标识 | 含义 | 应用 |
|------|------|------|
| DN | 公称直径 | 所有管道和管件 |
| NPS | 公称管径（美制） | 美标管件 |
| OD | 外径 | 金属管道 |
| ID | 内径 | 塑料管道 |
| SCH | 壁厚系列号 | 美标钢管 |
| PN | 公称压力 | 阀门和法兰 |

## 总结

**DN（公称直径）**是管道和管件的**名义规格标识**，不直接等于管道的内径或外径，而是一个标准化的参考数值。DN与英制尺寸有对应关系（DN15=1/2"，DN25=1"等），但不同材质和标准的管道，同一DN值对应的实际尺寸不同。在管件行业中，DN是标识产品规格的**基础语言**，必须准确理解其含义，避免与实际尺寸混淆。
