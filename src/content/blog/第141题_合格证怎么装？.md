# 合格证怎么装？

合格证是产品经过出厂检验合格后附上的标识。

它证明了这批产品已经通过质量检验，可以交付客户。

## 合格证的基本内容

一张规范的合格证通常包含以下信息：

| 信息项 | 内容示例 | 说明 |
|--------|---------|------|
| 产品名称 | 不锈钢卡压式管件 | 产品类别 |
| 规格 | DN25 | 具体规格 |
| 材质 | 304 | 材料标识 |
| 数量 | 100个 | 本批数量 |
| 批号 | 20260601-001 | 可追溯编号 |
| 检验结论 | 合格 | 检验结果 |
| 检验员 | 张三 | 检验责任人 |
| 检验日期 | 2026-06-01 | 检验时间 |
| 生产厂家 | XX公司 | 企业标识 |

## 合格证的装贴方式

### 方式一：随箱放入

合格证放在包装箱内，与产品一起交付。

- 优点：不会被意外损坏或丢失
- 缺点：客户开箱后才能看到
- 适用：所有管件产品的通用方式

### 方式二：贴在箱外

合格证粘贴在包装箱外面。

- 优点：直观，客户一眼可见
- 缺点：运输中可能脱落
- 适用：大宗出货或客户有要求时

### 方式三：贴在产品上

合格证直接贴在单件产品上。

- 优点：每件产品都有标识
- 缺点：成本较高，个别客户不需要
- 适用：高价值产品或客户有要求时

## 合格证装贴的注意事项

| 注意事项 | 说明 |
|---------|------|
| 信息准确 | 规格、数量、批号必须与实物一致 |
| 检验合格后才装 | 未检验或不合格的产品绝对不能装合格证 |
| 位置统一 | 放在箱内固定位置或贴在箱面统一位置 |
| 防止混淆 | 不同批次的合格证不能混用 |
| 字迹清晰 | 手写的合格证字迹要工整清晰 |

## 合格证与标签的区别

| 对比项 | 合格证 | 标签 |
|--------|--------|------|
| 作用 | 证明产品合格 | 标识产品信息 |
| 签发人 | 检验员 | 不限 |
| 装贴时机 | 检验合格后 | 包装阶段 |
| 法律意义 | 有质量责任追溯意义 | 主要用于识别 |

## 常见问题

| 问题 | 原因 | 对策 |
|------|------|------|
| 合格证信息错误 | 开单疏忽 | 增加复核环节 |
| 漏装合格证 | 包装环节疏忽 | 装箱清单纳入合格证检查 |
| 批号不一致 | 包装混批 | 加强批次管理 |
| 合格证损坏 | 运输中挤压 | 放在箱内保护位置 |

## 总结

合格证是产品质量的"身份证"。

严格按规范装贴合格证，不仅是满足客户要求，更是质量追溯的重要保障。
