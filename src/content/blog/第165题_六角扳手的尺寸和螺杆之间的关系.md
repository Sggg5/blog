# 六角扳手的尺寸和螺杆之间的关系？

六角扳手（内六角扳手）是管件设备和模具维修中最常用的工具。

了解扳手尺寸与螺钉规格的对应关系，才能正确使用。

## 六角扳手与内六角螺钉的关系

六角扳手的尺寸对应的是螺钉**头部内六角孔的对边宽度**（S值），而不是螺钉的外径。

| 螺钉规格（螺纹外径） | 六角扳手尺寸（内六角对边） |
|-------------------|----------------------|
| M3 | 2.5mm |
| M4 | 3.0mm |
| M5 | 4.0mm |
| M6 | 5.0mm |
| M8 | 6.0mm |
| M10 | 8.0mm |
| M12 | 10.0mm |
| M14 | 12.0mm |
| M16 | 14.0mm |
| M20 | 17.0mm |

## 常见对应关系记忆

| 螺钉规格 | 扳手尺寸 | 记忆技巧 |
|---------|---------|---------|
| M5 | 4mm | M5用4号扳手 |
| M6 | 5mm | M6用5号扳手 |
| M8 | 6mm | M8用6号扳手 |
| M10 | 8mm | M10用8号扳手 |
| M12 | 10mm | M12用10号扳手 |

**一般规律**：扳手尺寸 = 螺钉规格 - 2mm（大规格略有不同）。

## 六角扳手的规格标识

六角扳手通常用扳手对边宽度来标识：

| 标识 | 含义 | 对应螺钉 |
|------|------|---------|
| 4mm扳手 | 对边宽度4mm | M5 |
| 5mm扳手 | 对边宽度5mm | M6 |
| 6mm扳手 | 对边宽度6mm | M8 |
| 8mm扳手 | 对边宽度8mm | M10 |

## 使用注意事项

| 注意事项 | 说明 |
|---------|------|
| 尺寸匹配 | 扳手过大打滑损坏螺钉头 |
| 扳手质量 | 使用质量好的扳手，劣质扳手容易变形 |
| 插入深度 | 完全插入螺钉头内 |
| 用力方向 | 沿扳手轴线方向用力 |
| 避免撬动 | 不要用扳手撬东西，会弯曲变形 |

## 扳手尺寸不对的后果

| 后果 | 说明 |
|------|------|
| 螺钉头损坏 | 扳手过大或过小都会打滑 |
| 扳手变形 | 小扳手拧大螺钉，扳手扭曲 |
| 拧不紧 | 扳手过小，力矩传递不足 |
| 安全风险 | 打滑可能伤手 |

## 六角扳手与公制/英制的区别

| 系统 | 常见尺寸 | 适用 |
|------|---------|------|
| 公制（mm） | 2、2.5、3、4、5、6、8、10 | 国产设备和模具 |
| 英制（inch） | 1/16、5/64、3/32、1/8、5/32 | 进口设备 |

**使用扳手前确认是公制还是英制**，混用会导致损坏。

## 总结

六角扳手尺寸对应的是螺钉头部内六角孔的对边宽度，而非螺杆外径。

记住常用规格的对应关系，选择正确的扳手，是安全和高效操作的基础。
