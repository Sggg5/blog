# 千分尺如何使用？

千分尺（又称螺旋测微器）是精密测量中最常用的量具之一。

在管件制造中，千分尺用于测量管材壁厚、管件外径等尺寸，精度可达0.01mm。

## 千分尺的基本结构

| 部件名称 | 作用 |
|---------|------|
| 弓架 | 支撑整个千分尺 |
| 砧座 | 固定测量面 |
| 测微螺杆 | 活动测量面 |
| 固定套管 | 刻度基准线（主尺） |
| 微分筒 | 旋转读数筒（副尺） |
| 测力装置 | 保证测量力一致的棘轮 |
| 锁紧装置 | 锁定读数 |

## 千分尺的测量原理

千分尺利用螺旋传动原理，将螺杆的直线移动转换为旋转运动。

测微螺杆的螺距为0.5mm。

微分筒转一圈，螺杆移动0.5mm。

微分筒圆周上刻有50格刻度，每格代表0.5/50 = **0.01mm**。

## 千分尺的读数方法

读数步骤：

### 第一步：读固定套管（主尺）

固定套管上有两排刻度：

- 上排：每格0.5mm
- 下排：每格1.0mm

读出微分筒边缘之前的主尺数值。

### 第二步：读微分筒（副尺）

读出微分筒上与主尺基准线对齐的刻度数值。

### 第三步：相加

**总读数 = 主尺读数 + 微分筒读数 × 0.01mm**

### 读数示例

| 主尺读数 | 微分筒读数 | 最终读数 |
|---------|-----------|---------|
| 5.0mm | 23格 | 5.0 + 23×0.01 = 5.23mm |
| 7.5mm | 8格 | 7.5 + 8×0.01 = 7.58mm |
| 12.0mm | 35格 | 12.0 + 35×0.01 = 12.35mm |

## 千分尺的正确使用方法

### 使用前的准备

1. **清洁**：擦净砧座和测微螺杆的测量面
2. **校零**：合拢测量面，确认零位是否对齐
3. **检查测力装置**：确认棘轮功能正常

### 测量步骤

1. **放置工件**：将工件放在砧座和测微螺杆之间
2. **旋入螺杆**：旋转微分筒使测量面接近工件
3. **使用棘轮**：接近接触时改用棘轮，听到"咔咔"声停止
4. **锁紧读数**：轻轻锁紧螺杆，取下千分尺读数
5. **记录数据**：读数并记录

## 使用注意事项

| 注意事项 | 原因 |
|---------|------|
| 不要用力旋转微分筒 | 测力过大会影响精度或损坏量具 |
| 不要在工件旋转时测量 | 影响精度且不安全 |
| 测量前要校零 | 防止零位偏移导致读数错误 |
| 保持测量面清洁 | 灰尘和油污影响测量精度 |
| 轻拿轻放 | 千分尺是精密量具，跌落会损坏精度 |

## 千分尺的保养

- 使用后擦拭干净，涂防锈油
- 存放在专用盒中，避免碰撞
- 定期送计量室校准（通常每半年一次）
- 长期不用时，砧座和螺杆之间留少量间隙

## 千分尺与卡尺的对比

| 对比维度 | 千分尺 | 游标卡尺 |
|---------|--------|---------|
| 精度 | 0.01mm | 0.02mm |
| 测量范围 | 较小（0~25mm, 25~50mm等） | 较大（0~150mm） |
| 测量力 | 有测力装置控制 | 手感控制 |
| 适用场景 | 精密尺寸测量 | 一般尺寸测量 |

**精度要求高的尺寸用千分尺，一般尺寸用卡尺。**

## 总结

千分尺是精密测量的核心工具。

正确的使用方法和保养习惯，是保证测量精度的关键。
