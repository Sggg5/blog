# 检具如何设计？

检具是生产现场用于快速判断产品是否合格的专用检测工具。

好的检具可以让检验人员快速、准确地判断产品质量。

## 检具的作用

| 作用 | 说明 |
|------|------|
| 快速检验 | 比用通用量具测量快得多 |
| 降低技能要求 | 不需要高技能的检验员 |
| 统一标准 | 每个人用同一检具，标准统一 |
| 提高效率 | 适合批量检验 |
| 防止误判 | 通止规设计，减少人为误判 |

## 检具的类型

| 类型 | 原理 | 适用场景 |
|------|------|---------|
| 通止规（通端/止端） | 通过/不通过判定 | 内径、外径、螺纹检验 |
| 位置检具 | 检测孔位、安装位置 | 管件安装面检测 |
| 轮廓检具 | 检测产品轮廓形状 | 弯头角度、曲率检测 |
| 组合检具 | 多个检测功能集成 | 一件产品多个尺寸检测 |

## 检具设计的基本原则

| 原则 | 说明 |
|------|------|
| 基准明确 | 检具的定位基准与设计基准一致 |
| 精度足够 | 检具精度要比被测尺寸精度高3~10倍 |
| 操作简单 | 一线人员易于操作 |
| 刚性好 | 使用中不变形 |
| 耐磨 | 检测面材料耐磨，使用寿命长 |
| 轻便 | 便于搬运和使用 |

## 检具设计的步骤

### 第一步：明确检测要求

- 需要检测哪些尺寸？
- 尺寸公差是多少？
- 检测频率是多少？

### 第二步：选择检具类型

根据检测要求选择合适的检具形式。

### 第三步：确定基准

检具的定位基准必须与产品设计基准一致。

### 第四步：设计检具结构

- 定位方式：如何放置和固定产品
- 检测方式：通止规、塞规、比对等
- 材料选择：定位面、检测面的材料

### 第五步：精度计算

| 设计要素 | 要求 |
|---------|------|
| 制造精度 | 比被测公差高3~10倍 |
| 磨损裕度 | 考虑长期使用的磨损量 |
| 温度补偿 | 考虑使用环境温度的影响 |

### 第六步：制作和验证

- 加工制造
- 用标准件验证检具精度
- 用已知合格品和不合格品验证判定准确性

## 检具的材料选择

| 部件 | 常用材料 | 要求 |
|------|---------|------|
| 检测面（通止规） | 硬质合金或淬火钢 | 耐磨、高硬度 |
| 定位面 | 淬火钢 | 耐磨、不易变形 |
| 基体 | 铝合金或钢 | 轻便、刚性 |
| 手柄 | 塑料或铝合金 | 舒适、隔热 |

## 检具的管理

| 管理项目 | 要求 |
|---------|------|
| 编号管理 | 每个检具有唯一编号 |
| 周期校准 | 定期校准，确保精度 |
| 使用记录 | 记录使用频次和状态 |
| 存放 | 专用存放盒，避免碰撞 |

## 总结

检具设计需要结合产品特点、检测要求和现场使用条件。

好的检具要**精度够、操作简、耐用久**，才能真正发挥快速检验的价值。
