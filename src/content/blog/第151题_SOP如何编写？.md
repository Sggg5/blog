# SOP如何编写？

SOP（Standard Operating Procedure，标准作业程序）是车间生产中最核心的操作指导文件。

好的SOP能让新人按步骤操作就能做出合格的产品。

## SOP的定义和作用

| 作用 | 说明 |
|------|------|
| 标准化作业 | 确保每个人都用相同的方式操作 |
| 培训教材 | 新员工学习操作的指南 |
| 质量保证 | 按SOP操作才能保证产品质量 |
| 问题追溯 | 出问题时对照SOP分析是否违规 |
| 持续改善 | 改善SOP就是改善工艺 |

## SOP的基本结构

一份完整的SOP通常包含以下部分：

| 序号 | 要素 | 内容 |
|------|------|------|
| 1 | 文件编号 | 唯一编号，便于管理 |
| 2 | 产品名称 | 明确SOP适用的产品 |
| 3 | 工序名称 | 明确是哪道工序的SOP |
| 4 | 适用设备 | 使用的设备编号或类型 |
| 5 | 操作步骤 | 分步骤详细描述操作方法 |
| 6 | 关键参数 | 每个步骤的关键工艺参数 |
| 7 | 质量要求 | 中间检查和最终检验标准 |
| 8 | 安全注意事项 | 操作中需要注意的安全事项 |
| 9 | 工具清单 | 需要使用的工具和量具 |

## SOP编写的步骤

### 第一步：现场观察

到车间观察实际操作，了解真实的操作过程。

不要只坐在办公室凭想象写，要"三现主义"。

### 第二步：记录步骤

将操作过程分解为清晰的步骤。

- 每个步骤做一件事
- 步骤顺序不能颠倒
- 用简洁的语言描述

### 第三步：确定关键参数

每个步骤中，哪些参数是关键的？

| 工序 | 关键参数 |
|------|---------|
| 焊接 | 电流、电压、氩气流量、焊接速度 |
| 弯管 | 弯曲角度、弯曲速度、芯棒位置 |
| 冲孔 | 冲压力、冲孔位置 |
| 固溶 | 温度、速度、冷却方式 |

### 第四步：拍照或画图

关键步骤配合照片或示意图：

- 操作姿势照片
- 设备参数设置界面照片
- 产品放置位置照片
- 合格/不合格对比照片

### 第五步：编写初稿

将以上信息组织成SOP文档。

### 第六步：评审和修改

由工艺主管和班组长评审，确认内容准确后发布。

## SOP编写的基本原则

| 原则 | 说明 |
|------|------|
| 简单明了 | 一线操作工能看懂 |
| 具体量化 | 参数写具体数值，不说"适当" |
| 图文并茂 | 配合照片或图示更直观 |
| 可操作 | 步骤能实际执行 |
| 不断更新 | 随着工艺改进及时更新 |

## SOP的常见问题

| 问题 | 原因 | 对策 |
|------|------|------|
| 操作工不看SOP | SOP放在抽屉里吃灰 | SOP悬挂在工位旁 |
| SOP与实际不符 | 工艺变更后未更新 | 建立SOP变更管理流程 |
| 内容过于笼统 | 缺少具体参数 | 写明确切参数值 |
| 步骤混乱 | 编写时没有现场验证 | 现场验证后再发布 |
| 照片模糊 | 拍摄质量差 | 重新拍摄清晰的图片 |

## SOP的生命周期

| 阶段 | 活动 |
|------|------|
| 编写 | 初稿编制、评审 |
| 发布 | 批准、发放到工位 |
| 执行 | 操作工按SOP操作 |
| 检查 | 定期检查SOP执行情况 |
| 修订 | 工艺变更时及时修订 |
| 归档 | 旧版本归档，新版本替代 |

## 总结

SOP是生产管理的"法律"。

编写SOP的核心是：**去现场观察、步骤清晰、参数明确、图文并茂、持续更新。**
