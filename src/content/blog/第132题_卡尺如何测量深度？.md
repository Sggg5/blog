# 卡尺如何测量深度？

游标卡尺（简称卡尺）是制造现场使用频率最高的量具。

除了测量外径、内径外，卡尺的**深度尺**功能可以方便地测量孔深和槽深。

## 卡尺的基本结构

| 部件 | 功能 |
|------|------|
| 主尺 | 固定刻度尺 |
| 游标尺 | 滑动刻度尺（副尺） |
| 外测量爪 | 测量外径 |
| 内测量爪 | 测量内径 |
| 深度尺 | 测量深度（从游标尺尾端伸出） |
| 紧固螺钉 | 锁定读数 |

## 卡尺测深的方法

### 基本操作步骤

1. **清洁工件和卡尺**：确保测量面无灰尘、油污
2. **零位确认**：合拢量爪，确认零位对齐
3. **放置卡尺**：将卡尺主尺端面紧贴工件被测面
4. **推入深度尺**：推动游标尺使深度尺伸入孔或槽底
5. **施加适当力量**：轻轻推紧，不要用力过猛
6. **锁紧读数**：拧紧紧固螺钉后读数

### 关键要点

- **主尺端面必须与工件表面完全贴合**，否则读数偏大
- 深度尺底部必须与孔底或槽底接触
- 测量时保持卡尺垂直于被测面

## 常见测量场景

### 测量孔深

| 步骤 | 操作 |
|------|------|
| 1 | 将卡尺主尺端面放在管件孔口平面上 |
| 2 | 推动游标使深度尺深入孔底 |
| 3 | 保持卡尺垂直，读数 |

### 测量槽深

与孔深测量方法相同，将卡尺端面放在槽口平面上即可。

### 测量台阶差

将卡尺端面放在基准面上，深度尺接触台阶面。

## 卡尺测深的常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 卡尺端面未完全贴合工件 | 读数偏大 | 确保端面完全贴合 |
| 卡尺倾斜 | 读数偏大 | 保持垂直 |
| 用力过猛 | 深度尺弯曲变形 | 轻轻推紧 |
| 深度尺未到底 | 读数偏小 | 确认深度尺触底 |
| 未校零 | 系统性误差 | 测量前先校零 |

## 卡尺的读数方法

### 数显卡尺

直接读数，简单方便。

注意单位切换（mm/inch）。

### 机械卡尺

**读数 = 主尺读数 + 游标对齐格数 × 分辨率**

常见精度：

| 卡尺类型 | 分辨率 | 读数方法 |
|---------|--------|---------|
| 0.02mm卡尺 | 0.02mm | 游标50格 |
| 0.05mm卡尺 | 0.05mm | 游标20格 |

## 卡尺测深与专用深度尺的对比

| 对比项 | 卡尺测深 | 专用深度尺 |
|--------|---------|-----------|
| 精度 | 0.02mm | 0.01mm |
| 便捷性 | 高，一卡多用 | 专用，精度更高 |
| 适用场景 | 一般精度要求 | 高精度深度测量 |
| 深度范围 | 通常0~150mm | 可达300mm以上 |

## 总结

卡尺的深度测量功能虽然简单，但正确操作需要注意贴合、垂直和力度。

养成良好的测量习惯，才能获得准确的测量数据。
