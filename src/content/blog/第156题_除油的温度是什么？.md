# 除油的温度是什么？

除油是不锈钢管材管件表面处理中的关键工序。

除油温度直接影响除油效果和效率。

## 除油的目的

不锈钢管材在加工和储存过程中，表面会附着各种油脂：

- 切削油和润滑油的残留
- 拉伸油
- 手汗和指纹
- 储运过程中的防锈油

如果不除干净，这些油脂会影响后续工序（如酸洗、钝化、焊接）的质量。

## 常用除油方式及温度

### 碱性除油

最常用的除油方式。

| 参数 | 说明 |
|------|------|
| 温度 | **60~80℃** |
| 除油剂浓度 | 3%~5% |
| 时间 | 5~15分钟 |
| 方式 | 浸泡或喷淋 |

温度对除油效果的影响：

- 温度过低（<50℃）：除油剂活性不够，除油不彻底
- 温度适中（60~80℃）：除油效果好
- 温度过高（>90℃）：除油剂分解加快，消耗量增大

### 酸性除油

| 参数 | 说明 |
|------|------|
| 温度 | **常温~50℃** |
| 特点 | 常温即可操作 |
| 适用 | 轻度油污 |

### 有机溶剂除油

| 溶剂 | 温度 | 说明 |
|------|------|------|
| 丙酮/酒精 | 常温 | 局部除油 |
| 三氯乙烯 | 常温~40℃ | 工业批量除油（注意环保要求） |

### 超声波除油

在超声波作用下，除油效率大幅提高。

| 参数 | 说明 |
|------|------|
| 温度 | **50~70℃** |
| 频率 | 20~40kHz |
| 时间 | 3~10分钟 |
| 特点 | 除油效果好，适合精密管件 |

## 温度选择的原则

| 原则 | 说明 |
|------|------|
| 油脂种类 | 重油需要更高温度，轻油可以较低 |
| 材料要求 | 温度不能影响材料性能 |
| 后续工序 | 考虑与后续工序的衔接 |
| 能耗成本 | 温度越高能耗越大 |

## 除油效果的检验

| 检验方法 | 操作 | 合格标准 |
|---------|------|---------|
| 水膜破裂法 | 除油后用水冲洗，观察水膜是否均匀连续 | 水膜不破裂 |
| 擦拭法 | 用白纸擦拭表面 | 白纸无油渍 |
| 目视法 | 观察表面 | 无明显油污和水珠 |

## 总结

除油温度一般控制在 **60~80℃** 是最常见的选择。

但具体温度需要根据油污类型、除油方式和后续工序来综合确定。
