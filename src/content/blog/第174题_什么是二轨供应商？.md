# 什么是二轨供应商？

二轨供应商是指企业在关键物料或零部件上，除了主力供应商（一轨）之外，额外培养的**备用供应商**（二轨）。

建立二轨供应商不是对主供应商不信任，而是供应链风险管理的必要手段。

## 为什么要建立二轨供应商？

| 风险场景 | 如果没有二轨 | 有二轨的好处 |
|---------|------------|------------|
| 主供应商停产或断货 | 生产停线，无法出货 | 二轨立即顶上，保障供应 |
| 主供应商涨价 | 被动接受高价 | 有二轨作为谈判筹码 |
| 主供应商质量问题 | 无备选，只能等整改 | 可以切换到二轨 |
| 主供应商产能不足 | 订单延误 | 二轨分担产能 |

**一句话：二轨供应商就是供应链的"保险"。**

## 二轨供应商的建立原则

### 原则一：同步验证

二轨不是等到需要时才找，而是平时就要同步验证。

| 步骤 | 内容 |
|------|------|
| 样品送审 | 二轨供应商提供样品进行材质和尺寸检测 |
| 小批量试用 | 进行小批量生产验证 |
| 性能对比 | 与一轨产品对比质量指标 |
| 纳入名录 | 验证通过后纳入合格供应商名录 |

### 原则二：保持活跃

二轨供应商不是"养而不用"。

即使平时主要用一轨，也要定期给二轨一些订单，保持合作关系和供货能力。

| 维护措施 | 频次 |
|---------|------|
| 给予少量订单 | 至少每季度一次 |
| 信息同步 | 技术变更同步通知二轨 |
| 评审更新 | 与一轨同样参与定期评审 |

### 原则三：信息保密

向二轨供应商提供的技术信息需要控制范围，避免信息泄露。

| 保密措施 | 做法 |
|---------|------|
| 签署保密协议 | NDA覆盖关键技术参数 |
| 分级提供信息 | 只提供二轨完成订单所需的最低限度信息 |
| 分开图纸版本 | 可以使用简化版图纸 |

### 原则四：合理分配

| 供应模式 | 分配比例 | 说明 |
|---------|---------|------|
| 主供应模式 | 一轨70~80%，二轨20~30% | 最常用 |
| 双轨均衡 | 各50% | 两个供应商实力相当 |

## 哪些物料需要建立二轨？

| 物料类型 | 是否需要二轨 | 原因 |
|---------|-------------|------|
| 关键原材料（不锈钢钢带） | **必须** | 影响全部产品 |
| 专用辅料（焊丝、密封圈） | **建议** | 停供影响生产 |
| 通用辅料（润滑油、清洁剂） | 可以不需要 | 市场上容易买到 |
| 设备备件 | **建议** | 停机风险大 |
| 包装箱 | 可以不需要 | 替代性强 |

## 二轨供应商的管理

| 管理项目 | 具体要求 |
|---------|---------|
| 资质审核 | 与一轨相同的标准审核 |
| 样品验证 | 必须通过样品和小批量验证 |
| 质量跟踪 | 来料质量定期统计和对比 |
| 定期评估 | 每年评估二轨的综合表现 |
| 升级机制 | 二轨表现好可以升级为一轨或双轨 |

## 常见误区

| 误区 | 问题 | 正确做法 |
|------|------|---------|
| "有了一个供应商就够了" | 供应链脆弱 | 关键物料至少两个供应渠道 |
| "二轨质量不如一轨" | 可能是验证不充分 | 严格按标准验证二轨 |
| "维护二轨太麻烦" | 断供时更麻烦 | 平时维护好，关键时刻派上用场 |
| "怕得罪主供应商" | 商业正常行为 | 主供应商会理解，反而会提高服务质量 |

## 总结

二轨供应商是供应链风险管理的必要手段。

平时维护好，关键时刻才能派上用场。关键物料必须建立二轨供应渠道。
