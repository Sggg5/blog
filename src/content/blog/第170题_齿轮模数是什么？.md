# 齿轮模数是什么？

齿轮模数是齿轮设计中最基本也是最重要的参数。

管件设备中大量使用齿轮传动——弯管机、制管机、压机等设备的减速机构都离不开齿轮。理解模数，才能做好设备的选型、备件采购和维修维护。

## 什么是模数？

模数（Module，符号m）是**齿轮齿距与圆周率的比值**。

**m = p / π**

其中p为齿距（相邻两齿同侧齿面之间的弧长）。

**模数的物理意义**：模数越大，齿轮的齿越大，承载能力越强。

可以简单理解为：模数是齿轮牙齿的"大小尺寸"。

## 标准模数系列

我国采用的标准模数系列如下：

| 模数范围 | 具体数值 | 用途 |
|---------|---------|------|
| 小模数 | 0.3、0.4、0.5、0.6、0.8 | 精密仪器、小功率传动 |
| 常用模数 | 1.0、1.25、1.5、2.0、2.5 | **一般机械传动，最常用** |
| 中模数 | 3.0、4.0、5.0、6.0 | 中等功率传动 |
| 大模数 | 8.0、10.0、12.0 | 大功率、重型传动 |

**优先选用标准模数**，非标准模数需要定制刀具，成本高。

## 模数与齿轮尺寸的关系

模数决定了齿轮的基本尺寸：

| 计算公式 | 说明 |
|---------|------|
| 分度圆直径 d = m × z | z为齿数 |
| 齿顶圆直径 da = d + 2m | 齿顶高 = 模数 |
| 齿根圆直径 df = d - 2.5m | 齿根高 = 1.25倍模数 |
| 中心距 a = (m × z1 + m × z2) / 2 | 两齿轮中心距 |

**举例**：模数2.5，齿数40的齿轮：

- 分度圆直径 = 2.5 × 40 = **100mm**
- 齿顶圆直径 = 100 + 2×2.5 = **105mm**
- 齿根圆直径 = 100 - 2.5×2.5 = **93.75mm**

## 模数对齿轮性能的影响

| 性能 | 模数大 | 模数小 |
|------|--------|--------|
| 齿轮外形尺寸 | 大 | 小 |
| 承载能力 | 强 | 弱 |
| 传动精度 | 较低 | 较高（齿数相同时） |
| 噪音水平 | 较大 | 较小 |
| 适合转速 | 低速 | 高速 |
| 齿轮成本 | 较高 | 较低 |

## 如何选择模数？

选择模数需要综合考虑以下因素：

### 1. 传递力矩（最重要）

传递的力矩越大，需要的模数越大。这是选择模数的第一考量因素。

### 2. 转速

高速传动适合较小模数（减小惯量和离心力），低速重载适合较大模数。

### 3. 安装空间

安装空间有限时，选用较小模数搭配较多齿数来满足传动比。

### 4. 齿轮材料

材料强度越高，相同模数下承载能力越大。

### 5. 成本

标准模数的刀具便宜，非标准模数成本高。

## 模数与压力角

除了模数，齿轮的另一个重要参数是**压力角**（通常为20°）。

| 参数 | 说明 |
|------|------|
| 模数m | 决定齿的大小 |
| 齿数z | 决定齿轮直径 |
| 压力角α | 决定齿形角度，标准20° |

**模数和压力角相同的一对齿轮才能正确啮合。**

## 管件设备中的齿轮应用

| 设备 | 齿轮用途 | 常见模数范围 |
|------|---------|------------|
| 制管机 | 减速传动 | 2.0~4.0 |
| 弯管机 | 弯曲驱动 | 1.5~3.0 |
| 压机 | 减速机构 | 2.5~5.0 |
| 水涨机 | 液压系统传动 | 2.0~4.0 |

了解设备的齿轮参数，有助于备件采购和故障排查。

## 模数的测量方法

| 方法 | 操作 | 精度 |
|------|------|------|
| 齿轮卡尺 | 直接测量模数值 | 中等 |
| 公法线测量 | 间接计算 | 较高 |
| 齿轮投影仪 | 光学测量 | 高 |

## 总结

模数是齿轮"牙齿大小"的度量，直接决定了齿轮的承载能力和尺寸。

优先选用标准模数系列，根据传递力矩和转速合理选择。了解模数知识，有助于设备维护和备件管理。
