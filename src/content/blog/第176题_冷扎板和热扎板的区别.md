# 冷扎板和热轧板的区别

冷轧板和热轧板是不锈钢板材的两种基本形态。

它们从加工工艺到最终性能都有很大差异，选错了可能导致产品质量问题或成本浪费。

## 什么是热轧板？

热轧板是在**高温状态**（通常1000℃以上）下轧制的板材。

钢锭或连铸坯加热后通过轧机逐道次减薄，形成热轧板。

## 什么是冷轧板？

冷轧板是在**常温状态**下，以热轧酸洗板为原料进一步轧制的板材。

热轧板去除氧化皮（酸洗）后，在常温下通过冷轧机减薄到目标厚度。

## 核心区别对比

| 对比项 | 热轧板 | 冷轧板 |
|--------|--------|--------|
| **轧制温度** | >1000℃ | 常温 |
| **表面状态** | 暗灰色、有氧化皮或酸洗后粗糙 | 光亮、平滑 |
| **厚度范围** | 通常≥3mm | 通常0.3~3mm |
| **厚度公差** | 较大（±0.1~0.3mm） | 较小（±0.01~0.05mm） |
| **宽度公差** | 较大 | 较小 |
| **力学性能** | 强度较低、塑性较好 | 强度较高、硬度较大 |
| **表面质量** | 粗糙，有氧化色 | 2B面（哑光）或BA面（镜面） |
| **价格** | 较低 | 较高 |

## 表面质量对比

| 表面类型 | 特征 | 加工方式 |
|---------|------|---------|
| 热轧 No.1 | 暗灰色、不光滑 | 热轧后退火酸洗 |
| 冷轧 2B | 哑光银白色、较光滑 | 冷轧+退火+酸洗+平整 |
| 冷轧 BA | 光亮如镜面 | 冷轧+光亮退火 |
| 冷轧 No.4 | 拉丝纹路 | 2B面研磨 |
| 冷轧 HL | 连续拉丝纹路 | 2B面连续研磨 |

**管件行业中最常用的是2B面的冷轧板**。

## 性能差异的原因

### 热轧板

高温轧制过程中，材料发生了**再结晶**，消除了加工硬化。

- 强度和硬度较低
- 塑性和韧性较好
- 晶粒较大

### 冷轧板

常温轧制过程中，材料产生了**加工硬化**。

- 强度和硬度显著提高
- 塑性有所降低
- 晶粒被拉长，形成纤维组织
- 通常需要退火恢复部分塑性

## 用途对比

| 应用场景 | 推荐板材 | 原因 |
|---------|---------|------|
| 管材制作用钢带 | **冷轧** | 壁厚精度要求高，表面质量要求高 |
| 法兰下料（厚板） | 热轧或冷轧 | 取决于厚度要求 |
| 模具基体 | 冷轧板（45#或模具钢） | 加工精度要求高 |
| 模具工作面 | 冷轧板（Cr12MoV） | 需要高硬度 |
| 简易工装 | 热轧板 | 成本低，精度要求不高 |
| 装饰面板 | 冷轧板No.4或HL | 外观要求高 |

## 厚度转换关系

热轧板是冷轧板的原料。

| 热轧板厚度 | → 冷轧后厚度 | 压缩比 |
|------------|-------------|--------|
| 3.0mm | → 约1.2mm | 约60% |
| 4.0mm | → 约1.5mm | 约62% |
| 5.0mm | → 约2.0mm | 约60% |

冷轧的压缩比通常在**60%~80%**，需要经过多次轧制。

## 如何区分热轧板和冷轧板？

| 区分方法 | 热轧板 | 冷轧板 |
|---------|--------|--------|
| **目视** | 暗灰色、不光滑 | 银白色、较光亮 |
| **触感** | 粗糙、有颗粒感 | 相对光滑 |
| **厚度** | 通常较厚（≥3mm） | 通常较薄（≤3mm） |
| **标记** | 板面有喷印标记 | 可能有保护膜 |

## 总结

冷轧板精度高、表面好但价格贵；热轧板精度低、表面粗糙但价格便宜。

管件行业中，**钢带（制管用）必须用冷轧板**，法兰和工装可以根据需要选择热轧或冷轧。
