# 自工序完结是什么？管件生产质量自主管理模式

**自工序完结**（日语：自工程完遂，じこうていかんすい）是丰田生产方式（TPS）中精益管理的核心概念之一。它要求每个操作人员在完成自己的工序后，**自主确认**本工序的工作成果是否合格，确保不把不良品传递到下一道工序。这一理念在管件生产中具有重要的实践意义。

## 自工序完结的基本概念

### 定义

**自工序完结**是指操作人员在完成本工序的所有操作后，按照规定的标准**自主检验**本工序的产出物，确认符合要求后再传递到下一工序。如果发现不良，立即在本工序内处理，**不接受上一工序的不良品，不制造本工序的不良品，不流出本工序的不良品**。

### 核心理念

自工序完结包含三个核心理念：

1. **不接受不良**：发现上一工序传递来的不良品时，立即退回，不继续加工
2. **不制造不良**：严格按照标准作业要求操作，确保本工序不出不良
3. **不流出不良**：本工序完成后的产品必须经过自主确认，合格后方可传递

### 与传统检验的区别

| 对比维度 | 传统检验模式 | 自工序完结模式 |
|---------|-------------|---------------|
| 检验人员 | 专职QC检验员 | 操作人员本人 |
| 检验时机 | 工序完成后统一检验 | 每个工位即时检验 |
| 不良发现 | 批量发现，滞后期长 | 即时发现，滞后期短 |
| 不良成本 | 批量不良损失大 | 单件不良损失小 |
| 质量责任 | QC负责 | 每位操作者负责 |

## 自工序完结的实施要素

### 标准作业指导书

**标准作业指导书（SOP）**是自工序完结的基础。每道工序必须有清晰、可操作的标准：

- **操作步骤**：明确的操作顺序和方法
- **质量标准**：每个关键质量点的合格标准
- **检验方法**：如何判断本工序产出是否合格
- **异常处理**：发现不良时如何处理

### 自主检验方法

每道工序的自检方法应根据工序特点设计：

| 管件工序 | 自主检验内容 | 检验方法 |
|---------|-------------|---------|
| 管坯切割 | 切口平整度、长度精度 | 目视+卡尺测量 |
| 挤出成型 | 管材外径、壁厚、外观 | 游标卡尺+目视 |
| 管件成型 | 卡槽形状、尺寸精度 | 卡规+目视 |
| 端面平头 | 端面垂直度、平面度 | 角尺+目视 |
| 螺纹加工 | 螺纹通止规、外观 | 螺纹量规+目视 |
| 密封圈装配 | 装配到位、无遗漏 | 目视检查 |
| 包装 | 数量正确、标签清晰 | 点数+目视 |

### 异常处理机制

当操作人员在自检中发现不良时，应遵循以下处理流程：

1. **立即停止**：停止本工序的后续操作
2. **隔离不良品**：将不良品放入红色隔离盒
3. **记录信息**：在品质记录表上记录不良项目和数量
4. **查找原因**：分析产生不良的原因
5. **采取对策**：立即采取纠正措施
6. **报告班长**：异常情况报告班组长

### 目视化管理

自工序完结离不开**目视化管理**的支持：

- **检验标准看板**：在每个工位悬挂自检标准和合格样品
- **红绿灯标识**：绿色表示正常生产，红色表示异常停机
- **首件确认区**：每班次首件必须经过确认并展示
- **不良品展示台**：展示典型不良品，起到警示教育作用

## 管件生产中的自工序完结实例

### 卡压管件生产线

以一条卡压管件生产线为例，各工序的自工序完结要点：

**工序1——管坯切割**：
- 检查管坯长度（卡尺测量，公差±0.5mm）
- 检查切口质量（无毛刺、无倾斜）
- 确认材质无误（查看管坯标识）

**工序2——管端成型（卡压）**：
- 使用专用卡规检查卡槽深度和宽度
- 目视检查卡槽表面无裂纹、无划伤
- 测量成型后外径在公差范围内

**工序3——密封圈装配**：
- 确认密封圈型号和材质正确
- 目视确认密封圈完全入槽、无外露
- 确认装配数量正确

**工序4——包装入库**：
- 核对产品型号和数量
- 检查包装完整性和标签正确性

## 推行自工序完结的关键成功因素

| 成功因素 | 具体要求 |
|---------|---------|
| 管理层支持 | 领导重视，投入资源培训 |
| 员工培训 | 所有操作人员经过自检方法培训 |
| 标准明确 | 每道工序有清晰的自检标准 |
| 工具配备 | 每个工位配备必要的检验量具 |
| 激励机制 | 对自检表现优秀的员工给予表彰 |
| 持续改进 | 定期回顾自工序完结的执行效果 |

## 常见误区

- **误区一**：自工序完结就是取消QC检验 → 自检不能完全替代专职检验，两者是互补关系
- **误区二**：只要求不培训 → 操作人员需要学习检验方法才能有效执行
- **误区三**：重形式轻实效 → 自检记录不能造假，必须是真实检验结果

## 总结

自工序完结是精益生产中**质量自主管理**的核心理念，要求每位操作人员对自己的工序质量**负全责**。在管件生产中推行自工序完结，可以实现不良品的**即时发现、即时处理**，大幅降低不良品流出率和质量成本。推行自工序完结需要**标准作业、自主检验、异常处理和目视化管理**四大支柱的配合，是一项需要持续投入和改善的管理体系。
