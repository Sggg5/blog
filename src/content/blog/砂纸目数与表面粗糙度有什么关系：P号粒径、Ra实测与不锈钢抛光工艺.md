# 砂纸目数与表面粗糙度有什么关系：P号粒径、Ra实测与不锈钢抛光工艺

“用400目砂纸能不能做到Ra 0.8？”“内壁要求Ra 0.4，是不是换成800目就行？”不锈钢管件车间经常遇到这类问题。它们看似是在问同一个表面等级，实际混淆了**工具的粒度、加工形成的纹路和成品的测量结果**。结论先说清楚：在相同设备和条件下，磨料逐级变细通常有利于降低划痕起伏，但不存在通用于所有不锈钢产品的“某目数＝某个Ra”标准换算表。

## 一、先弄清“目数”究竟代表什么

日常说的80目、240目、400目，可能来自不同粒度体系。传统筛网“目”与单位长度筛孔数量相关；涂附磨具更常使用**FEPA P号**，例如P240、P400。两套编号不能只看数字就认定磨粒尺寸相同，采购砂带应同时约定标准体系、磨料材质和厂家型号。

ISO 6344-2:2021对应涂附磨具P12至P220的粗粒度，ISO 6344-3:2021对应P240至P5000的细粒度；它们规范的是**磨粒粒度分布**，而不是打磨后金属表面的粗糙度。尤其不要把P400误读成“每英寸400个砂粒”。

## 二、常用P号对应多大的磨粒？

下面列出P240至P1200的典型**中位等效粒径**。这些数值与ISO 6344-3:2021公布的粒度分布数据相对应，表示磨料颗粒分布中的特征尺寸，并非单颗磨粒的固定直径，更不是加工出来的沟槽深度。

| 涂附磨具粒度 | 中位粒径（约，μm） |
| --- | ---: |
| P240 | 58.5 |
| P320 | 46.2 |
| P400 | 35.0 |
| P600 | 25.8 |
| P800 | 21.8 |
| P1000 | 18.3 |
| P1200 | 15.3 |

应当注意：例如P400磨粒中位粒径约35微米，**绝不意味着加工面Ra就是35微米**。砂粒并不以自身完整直径压入金属；实际切入深度由接触载荷、磨粒形状、工件变形和材料去除状态共同决定。

## 三、为什么同样400目，Ra会不同？

想象两条产线都使用P400砂带，一条处理退火后的平整管坯，另一条处理带焊缝余高、局部硬化和深划伤的焊管。即使磨料标签完全相同，成品也可能有不同的Ra和Rz。

主要影响因素至少包括：**前道表面**是否已经消除深纹；砂带是新带还是磨钝的旧带；氧化铝与碳化硅等磨料的切削行为；磨削压力、线速度、进给、润滑冷却；管子是否摆动；以及抛光纹路与测量方向。粗砂留下的深沟不可能仅凭最后一次细砂轻轻扫过就自动消失。

更关键的是，Ra是轮廓起伏绝对偏差的平均量，Rz关注轮廓高度特征。两个表面可以测出相近Ra，却一个纹路均匀、另一个存在少量深沟。**不能拿Ra代表最深划伤，也不能拿视觉“镜面”代替Ra。**

## 四、不要照搬“目数—Ra对应表”

网上常见“240目对应Ra 1.6”“800目对应Ra 0.4”之类表格。这些数值也许是某个工厂在特定材料、设备、压力和磨削顺序下积累的经验，离开原工艺就不具备普适性。若没有试样、仪器条件和重复测试记录，它们不能作为质量证明书依据，更不能冒充国家或ISO规定的固定转换值。

## 五、不锈钢管车间怎样建立自己的对应关系？

先确定成品要求，例如内壁Ra≤0.8 μm，并明确这是指定位置单点上限还是统计规则。再选定一批同规格、同材质和同初始表面的304或316L管段，分组采用一致的砂带工艺；只改变末道粒度，例如P240、P400、P600、P800，其他参数尽量固定。每个条件要有多件重复样品，记录磨料批次及新旧程度。

对内壁应区分母材与纵焊缝区域，对长管兼顾头、中、尾；对外壁应记录抛光方向。以经过确认的粗糙度仪、相同滤波与评定条件测Ra，必要时同步记录Rz、最大值、离散程度和典型划伤。测量方向应在作业指导书中固定，避免一组顺磨纹、一组横磨纹，得到不可比较的数字。

最后把数据做成企业内部的**“粒度—实测Ra分布—缺陷率—加工时间”关联图**，选用满足交付要求且产能合理的工艺。记录要注明产品规格、设备、砂带型号、工艺参数和测量条件；换设备、换材料或换供应商后应重新验证，而不是永久沿用旧图。

## 六、采购和验收文件应该怎么写？

生产工艺卡可以写“粗磨P180→中磨P320→精磨P600”，但这只是待验证的**工艺示例**，不保证自动达到某个Ra。成品规范则应写清：内壁或外壁、Ra上限、测量区域与方向、仪器和评价条件、取样频次、判定方式，以及划伤、漏抛、磨削烧伤等外观要求。

涉及几何产品规范时，ISO 21920-2:2021定义轮廓参数，ISO 21920-3:2021涉及规范操作；旧图纸若采用其他标准版本，应按合同和技术条件核对，不能随意替换测量设置。如果客户只写“400目镜面”，应先确认其要的是纹理外观、磨料工艺还是量化的Ra指标。

对于输水管和卫生管，还要把抛光与耐蚀性分开判断。粗糙度合格不意味着焊接热变色、游离铁污染、酸洗钝化或洁净度就自然合格；过度抛光还可能使薄壁管局部减薄。最终应结合内窥镜、表面清洁、壁厚和产品标准进行放行。

## 结语

**砂纸P号回答“使用多细的磨料”，Ra和Rz回答“实际形成什么表面轮廓”，两者之间隔着完整的加工过程。** 对工厂最有价值的不是背一张漂亮的换算表，而是通过受控试验建立自己的工艺数据库，再用实测结果证明交付质量。
