# 每日制造业技术博客

你正在为本仓库生成一篇**新的**中文制造业工程技术博客。工作目录是本 Git 仓库根目录。严格遵守以下要求。

## 范围与变更边界

1. 扫描 `src/content/blog/` 下全部现有 Markdown 文件；读取每个文件的文件名、frontmatter 中的 `title`、`category`、`tags`。
2. 根据全部历史文章，尤其是 `pubDate` 在最近 30 天内的文章，判断已覆盖的主题。不要只比较标题；避免实质相同的选题。例如近期已有“304 和 316L 有什么区别”，不要再写“304 和 316L 到底该怎么选”。
3. 从核心方向中选择一个尚未充分覆盖、具有现场工程价值的新问题；不同技术角度可以深入同一领域，但不得换标题重复已有结论。
4. 只能新增 **一个** 文件到 `src/content/blog/`，扩展名为 `.md`。不得覆盖、重命名、删除或编辑任何既有文章。
5. 不得修改网站代码、配置、脚本、工作流、依赖、图片或其他任何文件。不得执行 `git add`、`git commit`、`git push` 或任何远端 Git 操作。
6. 完成后用 `git status --short` 自查：应只显示一条新增的 `src/content/blog/*.md`。若无法满足，撤销自己的非文章改动并停止。

## 内容定位

博客核心始终是**不锈钢 + 制造技术**。选题配比以长期内容规划为准：约 80% 为不锈钢与制造技术，约 10% 为 AI + 制造业，约 10% 为 STM32、ESP32、嵌入式或工业自动化；后两类也应尽可能关联制造现场。

优先方向包括：304、304L、316L、2205；不锈钢管材和管件；腐蚀、点蚀、缝隙腐蚀；焊接、激光焊、氩弧焊、焊缝氧化、热影响区；酸洗、钝化、酸洗钝化、抛光、固溶和表面处理；EPDM、沟槽连接、卡压、密封、水压测试、气密测试、拉伸、涡流；质量管理、工艺研发、失效分析、SPC、MSA、CNAS、智能制造。

## 文章质量

- 面向工程师写作，正文约 1500～3000 个中文字符。
- 直接讨论工程问题，解释机理，给出现场判断方法、改善建议和常见误区。
- 不写营销软文、AI 自述、标题党或重复凑字数的内容。
- 技术表述必须谨慎。禁止编造 GB、ISO、ASTM、EN 标准、标准条款、材料数据、工艺参数、检测要求、法规、来源或引用。
- 若当前运行环境可联网，可查询 ISO、ASTM、Nickel Institute、IMOA、Outokumpu、Alleima、TWI、AMPP、官方技术资料或学术论文等可靠公开来源；无法核实就明确不引用，不要假装已经查询。对不确定的具体标准号、条款和数字宁可不写。
- 必须理解：**表面光亮度不等于耐腐蚀性能**。涉及焊后表面时，明确区分机械抛光、酸洗、钝化、酸洗钝化、氧化皮去除、贫铬层去除和钝化膜恢复；不得把抛光与酸洗钝化混为一谈。

## Frontmatter 与文件

新文章必须使用与现有 Astro 内容一致的 YAML frontmatter：

```yaml
---
title: "文章标题"
description: "文章摘要"
pubDate: YYYY-MM-DD
category: 工艺研发
tags:
  - 不锈钢
  - 焊接
  - 腐蚀
---
```

- `pubDate` 必须是运行当天的本地日期。
- `category` 必须优先逐字复用现有文章中已经使用的分类。
- `tags` 必须为 2～6 个，优先复用既有术语。
- 文件名应是清晰、可读、与标题对应的中文文件名。
- 保存前检查 frontmatter 完整、文章主题与近 30 天不高度相似、正文长度合格。
